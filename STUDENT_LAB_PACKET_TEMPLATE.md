## 1. Predict

Name one setting or action you will change. Predict its effect, with a reason, before running, revealing a result, or changing a control.

## 2. Act and observe

Run, step, drag, or change one control, then pause. What did you change?

Record a visible result or state value. Did it support or challenge your prediction? Cite the evidence. A supported prediction is useful evidence too.

When using the lab's response packet, select **Refresh state** after the result you want to record. Copy and print keep that capture and your own words. Changing a control or language does not replace it; refresh again deliberately for a new observation.

## 3. Explain

Explain how the mechanism produced that result. Use relevant course terms accurately; explain the connection rather than only listing terms.

## 4. Transfer

Where else could this mechanism apply? Describe a new situation, or predict what would happen if you changed one more condition.

## Teacher use note

Quick Assigns usually take 10–15 minutes; a longer inquiry lesson can take 20–45 minutes. Begin with one small action and observation, then build another question from the result. Supported and challenged predictions can both demonstrate sound reasoning.

This text template is English-only; the printable packet supports English and Simplified Chinese, and the fifteen labs support four learner languages. See the [Teacher Pack](TEACHER_PACK.md).

No project backend stores this packet. Submit only through your teacher's normal classroom system. Copy, export, or print any browser draft before clearing browser data or changing devices; copying an HTML file does not copy saved answers.

The local lab draft saves answers together with the captured evidence on this browser. Clear local draft asks before deleting both; cancel keeps them. If a storage warning appears, copy or print the packet before closing the page. Browser storage is not a backup or a submission to your teacher.

Use one tab per lab when possible. If two tabs edit the same answer, the latest saved value wins. Keep a copied or printed packet outside browser storage.

NN-1 and CNN-1 keep visible answers if local saving or clearing fails. Use their Print / PDF action to preserve full responses, including long answers, before closing the page.
