# Public surface locale matrix

AI Playgrounds contains **15 learner applets and 15 Level-1 Quick Assigns with English, Simplified Chinese, Vietnamese, and Spanish support**. Educator/support surfaces and Level-2 Activity Packs have narrower language boundaries.

A passing learner-language check does not mean that every page in the website or every teaching resource is available in four languages.

| Surface | English | Simplified Chinese | Vietnamese | Spanish |
|---|:---:|:---:|:---:|:---:|
| All 15 learner applets, including Transformer, Agent, and Game Trees | yes | yes | yes | yes |
| All 15 Level-1 Quick Assigns | yes | yes | yes | yes |
| Standalone lab downloads and their Quick Assigns | yes | yes | yes | yes |
| Main catalogue/navigation | yes | yes | yes | yes |
| Teacher Pack | yes | yes | no | no |
| Curriculum Map | yes | yes | no | no |
| Research and citation page | yes | yes | no | no |
| NN-1 and CNN-1 Activity Packs and their index | yes | no | no | no |
| Download instructions and repository Markdown guides | yes | no | no | no |

Other support pages must be inspected individually; a link to a four-language lab does not make the linking page four-language. An isolated bilingual download notice also does not establish complete page coverage.

## Language-state requirements

Learner-language coverage includes dynamic labels, instructions, errors, featured experiments, scenarios, explanations, teacher prompts, Quick Assign prompts, accessible names, and packet/output headings within the declared surface.

Changing language must preserve the experiment state and learner-authored response text. Language round trips must restore the expected labels without silently restarting an experiment, changing a seed, or clearing a prediction or draft.

Automated semantic/state parity does not establish fluent-reader naturalness. Do not describe the whole website or all teaching materials as fully four-language, or infer equitable access from language availability alone. See [Localization](LOCALIZATION.md) and [Quality](../QUALITY.md).
