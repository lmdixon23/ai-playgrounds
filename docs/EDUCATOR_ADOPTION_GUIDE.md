# Educator adoption guide

## Smallest useful implementation

Use one applet, one prediction question, one controlled variable, and one explanation prompt. A complete first use can fit in 15–20 minutes.

1. **Predict:** learners state what they expect before changing a control.
2. **Run:** change one variable and observe the trace or output.
3. **Explain:** identify the algorithmic step responsible for the change.
4. **Stress-test:** choose an edge case or counterexample.
5. **Exit:** distinguish what the visualization shows from what it simplifies.

## Three ready paths

- **Classification:** `playgrounds/knn-classifier/` — vary *k*, inspect neighbours, and explain a decision boundary.
- **Search:** `playgrounds/search-pathfinding/` — compare heuristic choices and trace explored states.
- **Probability:** `playgrounds/bayes-classifier/` — separate prior information, evidence, and posterior belief.

## Classroom safeguards

The public applets do not require accounts or student submissions. For maximum privacy, download the relevant HTML file and run it offline; canonical-host analytics will not load. Do not place student names in share links, issue reports, screenshots, or public feedback.

## Evidence boundary

Use the suite as an inspectable instructional resource. Do not describe it as research-proven or accessibility-conformant until the corresponding studies or audits have been completed.
