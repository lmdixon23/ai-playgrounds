# AI Playgrounds v1.0.1 — launch hardening

This patch preserves the v1.0.0 algorithms and standalone-app architecture while synchronizing the public product, research record, evidence, analytics, and launch materials.

## Highlights

- Three-audience, five-minute start path on the landing page.
- Explicit evidence/claim boundary visible before applet selection.
- Standardized aggregate analytics across public pages, with no canonical-host tracking for offline copies.
- GPC, DNT, query-string opt-out, local opt-out, fixed campaign codes, and no transmission of experiment values.
- Durable v1.0.0 evidence bundle and a repeatable release-evidence workflow.
- Corrected Paper 7 verification record: 45 pass, 0 fail, 0 skip.
- Educator adoption guide, classroom pilot protocol, uptake-reporting definitions, Show HN package, portfolio copy, and distribution plan.

## Compatibility

No backend, account, build step, or runtime package is required to use an applet. Existing v1.0.0 applet URLs and saved states remain the compatibility target.
