# AI Playgrounds launch kit

## Canonical one-sentence description

AI Playgrounds is an open suite of twelve bilingual, offline-ready interactives that makes foundational AI algorithms manipulable, inspectable, and classroom-ready.

## Proof points

- 12 independent, single-file applets.
- English and Simplified Chinese instructional support.
- No account, backend, or installation required for use.
- 45 deterministic algorithm checks and a 63-case browser matrix for the v1.0.0 release record.
- Teacher materials, student labs, curriculum mapping, fidelity notes, and reproducible release evidence.
- MIT license and scholarly citation metadata.

## Show HN body

I built AI Playgrounds because many AI visualizations are either polished black boxes or isolated demonstrations that are difficult to use in a real classroom. This is a suite of twelve independent HTML applets covering search, probability, machine learning, computer vision, logic, and reinforcement learning. Each file works without an account or backend, supports English and Simplified Chinese, and exposes assumptions and limitations rather than presenting a production algorithm as a toy animation.

The release includes teacher and student materials, shareable experiment states, deterministic deployment, 45 algorithm checks, and a bounded browser matrix. The tests establish software behaviour for the tested cases; they do not establish learning gains or accessibility conformance.

I would especially value feedback on three decisions: whether the explanatory modes expose enough internal state, whether the one-file/offline constraint is worth the duplication it creates, and which applet would most benefit from a deeper technical trace next.

The suite covers search, probabilistic reasoning, machine learning, computer vision, logic, and reinforcement learning. Each applet combines hands-on manipulation with explanatory modes, classroom materials, fidelity notes, and inspectable algorithmic behaviour. No account or backend is required.

The software release is verified with 45 deterministic algorithm checks and a 63-case browser matrix. Those results establish bounded software behaviour—not learning effectiveness—so the next research stage is classroom usability and misconception-focused validation.

Educators can start with one 15-minute predict–run–explain activity; developers can inspect or reuse each standalone HTML file; researchers can audit the test evidence and claim boundaries.

## Engineering-focused post

AI Playgrounds is a deliberately constrained educational software system: twelve dependency-free HTML applications, deterministic public-site construction, bilingual content, shareable state, browser QA, and 45 algorithm regression checks. The design question was not “how many features can fit in a demo?” but “how much algorithmic state can remain inspectable while the artifact still works offline in a school browser?”
