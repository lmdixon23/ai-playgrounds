# Launch-hardening scorecard

Scores distinguish the **prepared local candidate** from the **fully closed live-release state**. The latter requires the remaining manual and account-bound gates; no score converts software testing into evidence of learning effectiveness.

| Area | Before | Prepared local candidate | After live/manual closure | Main improvement | Remaining closure gate |
|---|---:|---:|---:|---|---|
| Product coherence | 9.0 | 9.5 | 9.6 | Three-audience start path, unified evidence boundary, educator adoption flow | Deploy the synchronized site |
| Visual and instructional design | 8.5 | 9.4 | 9.5 | Bilingual five-minute pathways and predict–run–explain framing | Physical-phone, keyboard, practical screen-reader, and educator usability pass |
| Software release readiness | 8.8 | 9.5 | 9.7 | Exact-tag evidence bridge/rerun, durable evidence, retention, release workflow, provenance | Exact published-commit CI and manual smoke record |
| Portfolio readiness | 9.2 | 9.5 | 9.6 | Full case study, proof points, analytics/privacy, explicit role evidence | Apply and publish the separate portfolio patch |
| LinkedIn readiness | 9.0 | 9.6 | 9.6 | Educator, research, and engineering variants; alt text; measurable campaign source | Select posting cadence and publish |
| Show HN readiness | 7.8 | 9.4 | 9.5 | Direct start path, technical body, first-comment plan, critique responses, transparent limits | Signed-out live check and active launch availability |
| Research-companion readiness | 6.8 | 9.4 | 9.6 | Corrected final metrics, immutable provenance, evidence bundle, uptake protocol, pilot gates | DOI archive, final manuscript build, external review |

## Interpretation

The local candidate materially improves every area that was below 9.4. The live/manual column is not earned merely by possessing the package: it requires deployment, exact-commit verification, the bounded manual checks, and—only for the scholarly score—the DOI-backed archive and final paper build.
