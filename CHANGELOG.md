# Changelog

This is the reader-facing release index. The [website release history](https://lmdixon23.github.io/ai-playgrounds/release-notes.html) preserves the longer historical narrative. Published tags and download assets are version-specific and are not rewritten to match newer releases.

## v1.9.3

Restored language selection, Guided Challenge, and correct featured experiments at original-lab directory URLs. Added all-fifteen-lab directory/file/renamed-offline regression coverage. See [current release notes](RELEASE_NOTES.md).

## v1.9.2

CNF/SAT startup-sharing fix and restoration of the fuller public project README and documentation. See [published v1.9.2](https://github.com/lmdixon23/ai-playgrounds/releases/tag/v1.9.2).

## v1.9.1

Aligned the shared header controls, learning tabs, Guided Challenge, classroom section, reading width, and teacher-note placement of Transformer, Agent, and Game Trees with the original twelve labs. Preserved mechanism-specific controls, language/state behavior, and offline delivery. Added full-page layout regression checks across fifteen labs.

[Published v1.9.1](https://github.com/lmdixon23/ai-playgrounds/releases/tag/v1.9.1)

## v1.9.0

Quality and accessibility-engineering improvements, cross-lab visual checks, and fifteen independently usable offline HTML downloads. Wumpus World gained an icon key and larger, cell-scaled breeze and stench icons, without changing gold.

[Published v1.9.0](https://github.com/lmdixon23/ai-playgrounds/releases/tag/v1.9.0)

## Earlier releases and evidence

The [historical release notes](https://lmdixon23.github.io/ai-playgrounds/release-notes.html) describe earlier versions. The archived [v1.0.1 DOI](https://doi.org/10.5281/zenodo.21854217) identifies that version, not a later distribution.

Human learner/educator usability studies and human screen-reader validation are deferred for the v1.9 releases listed here. Software regression results do not imply learning gains, adoption, or WCAG conformance.
