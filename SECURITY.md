# Security

AI Playgrounds has no accounts, backend, database, or student-upload endpoint.

Report a security issue privately through the repository owner's contact channel rather than opening a public issue when disclosure could expose users. Include the affected page, browser, reproduction steps, and expected impact.

Do not send credentials, student records, or unnecessary personal information. See [Analytics and privacy](docs/ANALYTICS_AND_PRIVACY.md) for the public site's data boundary.
