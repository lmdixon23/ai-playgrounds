    Evidence boundary and misconceptions
    
This is a fixed toy decoder-like calculation, not a pretrained language model. It does not search the internet, store complete answers, reproduce frontier-model internals, or establish how a production model reasons. A token is not necessarily one word. The causal mask is a structural restriction on permitted source positions. Position vectors are not word meanings. The highest-probability token need not be sampled in a stochastic generator.
